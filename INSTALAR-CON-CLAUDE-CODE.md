# Instalar el bot con Claude Code

Abre Claude Code en la computadora del bot, dale la carpeta del bot (o el .zip) y pega este texto:

```text
Instala el Bot de TikTok de esta carpeta (si no la ves, busca el .zip «BOT-TIKTOK-APP» en Descargas y descomprímelo). Lee el README.md y ejecuta el instalador de mi sistema: MAC/INSTALAR.command o WINDOWS/INSTALAR.bat. Háblame en español sencillo. No modifiques el código, no toques contraseñas ni el archivo .env y no inicies sesión en TikTok por mí. Si sale un error o un captcha, para y enséñamelo. Al terminar, abre http://127.0.0.1:8765 para que yo cree la contraseña del panel y conecte mi cuenta de TikTok con el código QR.
```
